# Changelog

## 1.0.0 — 2026-10-18

- Extracted the verified experiment cores into a portable local source release.
- Added bounded training, fixed-C validation export, immutable teacher records, shared observation adapters and one-stage Python commands.
- Preserved the original architecture, score losses, localization updates, aggregate channel generator and non-official MDVALSE numerical kernels.
- Added CPU-safe lazy loading of the original CUDA extensions; removed machine paths and the completed experiment's date cutoff.
- Bound evaluation resume to backend and effective network sources; recovery checkpoints now restore the selected weights and their committed validation-history prefix together.
- Included C/A/B reference aggregate tables and PNG/PDF results; E3 includes MDVALSE for A/B and E2 displays kappa=0/5/10 while preserving -5 in tables.
- Added English/Chinese instructions, citation, MIT copyright Boyu Teng, retained third-party licenses, provenance and integrity checks.
- Excluded datasets, raw result MAT files, checkpoints, private logs and machine configuration.
