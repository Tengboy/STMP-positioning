# STMP localization reproduction

Code for **Enhancing Localization Accuracy via Score-Based Interference Suppression**, Boyu Teng and Xiaojun Yuan, *IEEE Wireless Communications Letters*, 2026. [Paper DOI](https://doi.org/10.1109/LWC.2026.3708142) · [中文说明](README_zh.md) · [Citation](#citation) · [full reproduction recipe](docs/REPRODUCING.md) · [result interpretation](docs/RESULTS.md)

This release contains MATLAB channel generation, first- and second-order score-network training, STMP/ML/CRB evaluation, Boyu Teng's non-official MDVALSE baseline, and E0–E3 plotting. It includes aggregate results and PNG/PDF figures from the completed new-data reproduction. Raw MAT files, datasets, checkpoints and private machine configuration are intentionally omitted. They are generated by the documented pipeline; there are no hidden pretrained-model requirements.

## View or redraw the supplied results

Open [C-domain performance](results/reference/figures/fresh_historical/E1_all_trials.png), [iteration performance](results/reference/figures/fresh_historical/E2_all_trials.png), [A/B generalization including MDVALSE](results/reference/figures/fresh_historical/E3_all_trials.png), or [training validation](results/reference/figures/training_validation.png).

Only NumPy and Matplotlib are needed to redraw the aggregate CSVs:

```bash
python -m pip install -r requirements-plot.txt
python scripts/plot_reference_results.py --output work/reference_plots
```

This command redraws stored results; it does not train or run new Monte Carlo trials. `--variant paper` selects the separately labelled numerical-convention diagnostic.

## Reproduce from scratch

Use MATLAB R2023b for channels and MDVALSE, and Python 3.11 / PyTorch 2.4.1 on a CUDA GPU for full training and evaluation. A CPU smoke path is included. Run commands from the release directory; all generated files default to `work/`, or pass an absolute `--root` to Python and the same run-directory path to MATLAB. See [environment setup, exact commands, transfers and resume rules](docs/REPRODUCING.md).

| Stage | Entry point | Main output |
| --- | --- | --- |
| Channel generation | `matlab/run_channel_generation.m` | Disjoint C train/validation/test; A/B test |
| Shared observations | `python scripts/run_experiment.py observations` | Identical observations for every method |
| First-order training / selection | `train1`, then `freeze1` | C-validation-selected immutable teacher |
| Second-order training / selection | `train2`, then `freeze2` | Student with fixed first-order teacher |
| Covariance and performance | `covariance`, then `evaluate` | E1–E3 raw trial results, ML and CRB |
| Baseline | `matlab/run_baseline.m` | 18 C/A/B MDVALSE points |
| New-result figures | `plots`, then `e0` | Full-population and historical-filtered views |

The default `historical` variant follows the validated executable conventions used to reproduce the reported trends. The optional `paper` variant changes initialization and variance/covariance conventions and is a diagnostic, not a substitute for the primary route. Historical filtered views are explicitly conditional; all-trial summaries retain failed and extreme-error trials. E2 displays kappa=0,5,10 dB; kappa=-5 dB remains in the experiment matrix and tables. [Details and limitations](docs/RESULTS.md).

## Files and verification

- `configs/`: exact channel-network and experiment parameters.
- `scripts/`, `matlab/`, `baseline/`: stage entry points and computational routines.
- `third_party/`, `licenses/`: retained source dependencies and license texts.
- `results/reference/`: compact CSV, metadata, and final PNG/PDF results.
- `tests/`: numerical, selection, failure-retention and portability regression checks.
- `docs/VERIFICATION.md`: what was tested for this release; `SOURCE_MANIFEST.json` records source provenance and release hashes.

```bash
python -m unittest discover -s tests -v
python scripts/verify_package.py
```

Cite the paper using [CITATION.cff](CITATION.cff). This source package is a reproducible research release; results can vary across GPU hardware, software versions and batching, as documented in the result notes.
